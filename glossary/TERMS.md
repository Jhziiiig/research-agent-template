# Controlled terms

Use existing terms when possible. Add a term only when it prevents a real ambiguity or provides a stable shorthand for an already explained operation.

## Rule for new terms

At first use:

1. Describe the concrete operation or observation using existing words.
2. Introduce the new term as shorthand.
3. Use the same term consistently afterward.
