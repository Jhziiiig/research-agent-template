# Run One Research Task

Read `PROJECT.md`, `memory/CURRENT.md`, `work/ACTIVE_TASK.md`, the linked plan section, and only the evidence needed for the active task. If the task is not approved or lacks a necessary scientific choice, prepare the missing choice and stop.

Follow `workflow/OPERATING_MODEL.md` and the active task exactly:

1. Restate the question, input, output or target, changed element, fixed elements, evaluation reference, completion condition, and stop condition in concrete language.
2. Execute only the allowed work. Preserve source data and prior evidence.
3. Run the specified checks. Repair mechanical failures and re-run affected checks without changing the research question.
4. Classify discoveries as blocking, bounded diagnostic, or backlog. Record a diagnostic's parent, limit, stop condition, evidence, and return point before executing it.
5. Save evidence and distinguish observed facts from interpretation.
6. Create a review packet from `templates/REVIEW_PACKET.md` and update durable state as permitted.
7. Stop at the human decision gate. Recommend but do not activate the next task.

Do not claim completion for skipped, failed, inferred, or planned work. Do not introduce a new dataset, target, major model family, comparison, metric, or claim without the required human decision.
